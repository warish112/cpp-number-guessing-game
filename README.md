# C++ Number Guessing Game 🎯

A simple number guessing game built using C++.

## 🎮 How It Works

The program generates a random number between **1 and 100**.

The player keeps guessing until they find the correct number.

The program provides hints:

- 🔼 Too high
- 🔽 Too low
- ✅ Correct

It also counts the number of attempts.

## 🧠 Concepts Used

- Variables
- `if / else if / else`
- `do-while` loop
- `cin` and `cout`
- Random number generation
- `srand()` and `rand()`
- Basic C++ programming logic
